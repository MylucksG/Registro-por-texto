# Glosario para no expertos

Palabras que aparecen en este repositorio, explicadas sin tecnicismos.

| Palabra | Qué significa |
|---|---|
| **Teorema** | Una afirmación matemática que ya está demostrada. |
| **Conjetura** | Una afirmación que los matemáticos creen cierta pero nadie ha demostrado todavía. Cuando alguien la demuestra, pasa a ser teorema. |
| **Demostración** o **prueba** | El razonamiento paso a paso que muestra que una afirmación es cierta. |
| **Contraejemplo** | Un caso concreto que muestra que una conjetura es falsa. Basta uno solo. |
| **Manuscrito** o **paper** | Un artículo científico que explica un resultado y su demostración. |
| **Familia** | En `openai/math`, un grupo de manuscritos sobre el mismo resultado: el principal y sus variantes. |
| **Lean** | Un programa que comprueba demostraciones de forma automática. Ver [¿Qué es Lean?](que-es-lean.md). |
| **Formalizar** | Reescribir una demostración en un lenguaje como Lean para que una máquina pueda comprobarla. |
| **Revisión por pares** | Cuando otros expertos leen un artículo y buscan errores antes de darlo por bueno. Los resultados de `openai/math` todavía no han pasado por ella. |
| **Algoritmo** | Una receta paso a paso para que un ordenador resuelva un problema. |
| **Algoritmo galáctico** | Un algoritmo que en teoría es más rápido, pero solo gana con datos de un tamaño tan enorme que nunca se usa en la práctica. |
| **Cota** | Un límite demostrado. Por ejemplo, "este problema no se puede resolver en menos de X pasos". |
| **Problemas del Milenio** | Siete grandes problemas por los que el Instituto Clay ofrece un millón de dólares cada uno. Solo uno está resuelto. |
