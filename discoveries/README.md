# Descubrimientos de la IA

Aquí se registran descubrimientos, resultados y anuncios hechos por sistemas de IA, con un análisis independiente de cada uno. Cada entrada responde a las mismas preguntas.

## Cómo añadir una entrada

1. Copia `_plantilla.md` a un archivo nuevo, por ejemplo `2026-10-openai-math.md`.
2. Rellena cada sección. Si no sabes algo, escribe "no verificado" en vez de dejarlo en blanco.
3. Enlaza la entrada desde el README principal.
